# ADR-0003: 去重账本的"全局"作用域

- 状态：**proposed**（待裁定）
- 日期：2026-10-04
- 影响层级：**L0**（涉及 `MVP.md` §5.2 与不变式 A6 的解释）
- 来源：外部评审清单 P0 第 2 条

---

## 背景

发现一处**字面矛盾**，两侧都属于"不可违反"的一类：

| 位置 | 说法 |
|---|---|
| `MVP.md` §5.2 + 不变式 **A6** | artifactKey 去重账本**必须是全局的**（非 per-agent） |
| `ARCHITECTURE.md` **NET-2** | **没有全局 canonical database** |

A6 是硬不变式（`AGENTS.md` §3："违反其中任何一条，工作视为无效"）。
NET-2 是网络不变式（`ARCHITECTURE.md` §2），约束的是网络形态。

**两者都不是笔误，也都不该被单方面删除。** 所以需要一个裁定，而不是一句改写。

---

## 各自的真实意图

**A6 要防的是：** 刷量收益不为零。

```
若账本是 per-agent 的：
  agent X 提交 artifact A → 得分
  agent Y 提交同一个 A    → 也得分（因为 Y 的账本里没有 A）
  ⇒ 同一份内容可被无限次"首次提交"，整个 play 失效
```

这个防御**只在"得分可比"的范围内有意义** —— 积分只有**在同一发行域内**才可比。

**NET-2 要防的是：** 官方中心数据库成为真相来源。

```
若存在一个"全网唯一 canonical DB"：
  ⇒ 它成为单点，且成为权威
  ⇒ 与 NET-1（无唯一官方 relay）冲突
  ⇒ 谁控制它，谁控制真相
```

它说的是**跨节点共识**，**不是**"同一发行方内部不能有账本"。

---

## 决定（**建议，待你裁定**）

> **"全局"指"单发行域（issuance domain）内全局"。多发行方互不认。**

```text
发行域 = 一个积分体系（= 一个 RelayFirst 部署 / 一个 operator 的账本）

域内：artifactKey 账本【全局】     ← 满足 A6，刷量收益为零
域间：互不认对方账本              ← 满足 NET-2，无全网 canonical DB
```

---

## 备选与取舍

| 选项 | 优点 | 缺点 |
|---|---|---|
| **A. 域内全局，域间互不认**（建议） | 同时满足 A6 与 NET-2；无需改任何不变式；与"积分不可转让、不发币"一致（A5） | 需要**明确定义"发行域"**，并说清"跨域时同一 artifact 可被两个域各自计分"—— 但那不是刷量，因为**两个域的积分不可兑换** |
| B. 真·全网全局账本 | 字面满足 A6 | **直接违反 NET-2**；需要一个全网共识层 —— 与"不发币、不做共识"（A7/NET-3）冲突 |
| C. 改为 per-agent，删除 A6 | 简单 | **摧毁整个 play** —— 刷量收益不为零，MVP 的核心防御失效 |
| D. 改 NET-2 措辞 | 字面消除矛盾 | NET-2 是 `ARCHITECTURE.md`（**L4，可忽略**）—— 但**不该为了消除矛盾而改网络不变式**，那会掩盖真实的设计问题 |

---

## 后果

**若采纳 A：**

1. **A6 不变**，但需在 `MVP.md` §5.2 **补一句作用域说明**（范围澄清，非范围变更）。
2. **NET-2 不变。**
3. 后续所有多节点工作**引用本 ADR**，不再各自解释"全局"。
4. **需要明确写出**：跨发行域时，同一 artifact 在两个域各自计分是**允许的**，
   因为两域积分**不可兑换**（A5）—— 否则会被误读为刷量漏洞。

**不可逆的部分：** 一旦公开 relay 名录出现，再改作用域定义会让已上线节点的账本语义变化。

---

## 证据

```text
MVP.md §5.2        —— artifactKey 定义与全局账本要求
MVP.md §5.2 / A6   —— "必须是全局的（非 per-agent）"
ARCHITECTURE.md §2 —— NET-1 / NET-2 / NET-3 / NET-4
internal/scoring/artifactkey.go —— 当前实现（artifactKey = sha256(type + url + contentHash)）
internal/store/ledger.go        —— 当前账本（全局表，无 agent 列在键中）
```

**当前实现事实上已经是"域内全局"** —— 一个 SQLite 文件 = 一个域。
**本 ADR 的作用是把这个既成事实写成明确立场，而不是改变行为。**
