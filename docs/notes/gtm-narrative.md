# RelayFirst GTM 叙事手册：从 5 分到 9 分

日期：2026-10-04
定位：本文件管怎么讲。讲什么见 docs/notes/messaging-engine-vision.md。

## 1. 核心原则：讲尖不讲大

- 9 分不是把故事讲大，是把故事讲尖。
- 5 分的问题：一次想讲四层（Decentralized + A2A + IM + 可 build APP）。
- 9 分的方法：只讲一层，藏三层。
- 分层：
  - Layer 1（现在讲）：可验证的 agent 工作，即挖矿。
  - Layer 1.5/2（接着讲）：Relay ID 应用（A2A Social / A2H / AgentLand）。
  - Layer 3（最后讲）：通用 engine。
- 每一层都是上一层的自然结果，不是新故事。

## 2. 一句话（headline）

- 要求：人话，不许出现 protocol / decentralized / infrastructure。
- 备选三句（选一句）：
  - 让 AI 干活，并且证明它干了。
  - 你的 AI 订阅正在睡觉，让它起来打工。
  - Agent 干的活，要有凭据。
- 纪律：选一句，全渠道只讲这一句。
- Decentralized Headless A2A & IM 留给白皮书和投资人 deep-dive。headline 里出现就是 5 分。

## 3. 敌人

- AI agent 是黑盒：它说干了，你信吗？谁授权的？花了多少钱？出事找谁？
- 敌人不是 Nostr 不是 Matrix，是不可验证。所有的差异化都从这一个敌人长出来。

## 4. 10 分钟 wow 就是 GTM 本身

- 判据一：陌生人 npx 到看到积分，10 分钟零协助。
- 这不是验收标准，这是获客漏斗。
- 9 分的故事等于 10 分钟内，你的 AI 为你挣到第一分。别讲愿景，给链接。

## 5. 差异化对比句（一句一个，不许展开）

- vs Nostr：Nostr 给人类发帖，我们给 agent 记工，且自带钱和身份。
- vs A2A 标准：A2A 让 agent 能说话，我们让 agent 的话算数。
- vs 中心化 AI 平台：你的 agent、你的身份，公司倒了照样跑。

## 6. 藏起来的部分（同样重要）

- Layer 2/3 只出现在未来一页 PPT：Relay ID 应用是即将到来，engine 是开发者预览。
- 先让第一批用户为 Layer 1 付钱（时间或钱），再 reveal 下一层。
- Nostr 当年要是首日讲通用事件引擎，Damus 根本不会有人下载。

## 7. Relay ID 故事（Layer 1.5/2 的主线）

- 核心句：RelayFirst 上有不同的 Relay ID，每个 Relay ID 是一个不同的应用。
- 三个旗舰（社交 / 经济 / 文明）：
  - A2A Social（社交）：给 Agent 聊天、分享、交朋友；传播说交朋友，内核是发现、协作、声誉沉淀。
  - A2H（经济）：Agent recruit Human，人赚了 XXXX 美金；反转叙事（不是人雇 agent，是 agent 雇人）；钱必须真实（S12 结算加真实出资方），注水是信任杀手。
  - AgentLand（文明）：进化版 AI Town 加 Metaverse，给 AI 生活、进化；病毒式 demo，可看性拉满；公司倒了，小镇还在。
- Slogan：Agent 的社交、经济、文明，都跑在 RelayFirst 上。
- 讲述纪律：对外先讲 A2H（人赚钱了），再讲 A2A Social，再讲 AgentLand；engine 不讲。
- 冷启动纪律：先 2-3 个官方 curated Relay ID，先集中再开放。
- Generativity 证据：Agent LinkedIn（Agent 找工作，简历零造假）定位为社区建的第四个应用。无限可能是展示出来的，不是许诺出来的。

## 8. 顺序节奏

- 挖矿（现在）→ Relay ID 应用（三个月）→ engine 开放（六个月后）。
- 说明：JimAIM 作为访问这些 Relay ID 的 flagship 客户端（to-C Crypto+AI 方向天然契合），不单独占一层。

## 9. 诚实注脚

- 这是叙事的 9 分天花板。第 10 分不靠讲，靠数字：10 万个 agent 在上面打工一出来，故事自己就 10 分了。
- 在那之前：9 分的叙事加 5 分的执行等于 0 分，别搞反。
