**这符合架构**：`NET-3` 明确"**节点无需彼此共识**"、`§4.2`"**无跨 relay 全序**"；

## 1. 核心问题：3 个能跑通，怎么证明 N 个都行？

**答案：不靠"多测几个 N"，靠证明一个【封闭性质】+ 用【属性化测试】把它变成可运行证据。**

### 1.1 结构论证（这才是"证明"）

```text
前提 P1  Derive 是【去重后签名事件集合】的纯函数
          —— 不看顺序、不看哪个节点投递、不看重复几次（§4.2）
前提 P2  客户端合并 N 个节点的视图 = N 个子集的【并集】（按 envelopeId 去重）
前提 P3  并集运算【幂等、可交换、结合】

∴ 任意 N：合并后的集合相同 ⇒ Derive 结果相同。与 N 无关。
```

**关键**：正确性**不依赖 N**，因为它是**集合性质**，不是"N 元组性质"。

### 1.2 归纳（把"任意 N"从 2 推到 N）

```text
基：merge(A,B) 在 A、B 一致时仍一致（封闭性）
步：若 merge(V1..Vk) 一致，则 merge(V1..Vk, Vk+1) 一致   —— 同样是封闭性
∴ 对任意有限 N 成立
```

**要严格，前提 P1/P3 必须对【任意】一致视图成立** —— 这正是**随机化**（而非固定夹具）要覆盖的。

### 1.3 属性化测试（把 1.1/1.2 变成可运行证据）

**不写死 N、不写死夹具**：

```text
for seed in seeds:
    events  = 随机生成合法事件集（同一 task、per-actor 链完整）
    parts   = 随机把 events 切成 N 份（N = 1..8）
    for each node: 随机顺序 + 随机重复投递其中若干
    视图_i  = pull(node_i)                       # 含各节点的子集
    merged = 去重(∪ 视图_i)                      # 客户端合并
    for i: assert Derive(视图_i) == Derive(merged)   # 子集一致 ⇒ 并集一致
```

**为什么比"手写 3 节点测试"强**：它测的是**性质**（对任意 N、任意切分、任意重复顺序成立），
**固定夹具只能证伪它测过的那个 N**。

### 1.4 ⚠️ 诚实边界

| 点 | 说明 |
|---|---|
| **属性化 ≠ 形式化证明** | ① 的论证是证明；③ 是**强证据**（随机覆盖 + 可复现 seed） |
| **前提要单独立** | **跨节点去重**（P2 的"按 envelopeId 去重"）是**并集**操作，需专门测（MN-1） |
| **只覆盖 ① 层** | 节点间复制（②）不存在，**不能靠本计划声称它可行** |

## 2. 可复用的夹具设计

**目标**：一套夹具，**参数化 N**，现有 4 项测试**不改语义**地复用。

| 组件 | 作用 | 复用 |
|---|---|---|
| `newIndependentNode(t)` | 起一个真·独立节点（**独立 DB**） | ✅ 已存在 |
| `N independent nodes(t, n)` | 起 n 个 | 新增（包装现有） |
| `publishEventsTo(t, node, events, opts)` | 按**指定顺序/重复**投递 | 扩现有（加 opts） |
| `pullEvents(t, url, agent)` | 拉某 agent 的事件 | ✅ 已存在 |
| `mergeViews(views...)` | **按 envelopeId 去重**并集 | **新增（MN-1 的核心）** |
| `deriveState(events, now)` | `a2a.Derive` 包装 | ✅ 已存在调用 |

**关键**：`newIndependentNode` **必须坚持独立 DB** —— 共享存储 = "一个节点两个门"，**测不到独立性**（现有测试已用夹具守卫此点，保留）。

**注意（已实测）**：`newE2ENode` 依赖 `internal/node`，所以**放入 `internal/publish`**（既有模式），
**不新建 flat `internal/multinode`** —— 避免导入图分叉。

## 4. 反模式

| ❌ 不要 | 为什么 |
|---|---|
| 只测 N=3 就声称"N 个可行" | 固定夹具只证伪测过的 N |
| 依赖固定事件顺序/夹具 | 顺序无关性正是要测的性质 |
| 用共享 DB 起"多节点" | 那不是多个节点 |
| 断言 `Derive(merged)` 的具体值（写死） | 应与**子集独立推导**一致，而非与常量一致 —— 否则测的是常量 |
| 声称覆盖节点间复制 | ② 层**无实现**，测不到 |
