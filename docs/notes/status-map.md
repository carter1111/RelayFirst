## 4. 今天一个测试者能跑到哪？（UAT 可跑性）

**命令链全部就位**（实测）：`mine` ✅ / `status` ✅ / `settle` ✅ / **`claim` + `claim --web`** ✅ / `balance` ✅ / `spend` ✅ / `bind` ✅ / `heartbeat` ✅。

**UAT 路径（BYO key，今天可跑）**：
```
1. export RELAYFIRST_PRIVATE_KEY=0x…      （自备密钥；init 未实现）
2. relayfirst config set provider local
3. relayfirst mine --once --source <url>  （干活 → work → 回执）
4. relayfirst status                      （看 points / 待结算预估）
5. relayfirst settle                      （结算 → points + balance root）
6. relayfirst claim --web                 （只读 claim 视图）
```
**唯一被 `POL-SECRETS-1`+D2 挡住的是"第 1 步的一键版"** —— 其余**今天可跑**。
