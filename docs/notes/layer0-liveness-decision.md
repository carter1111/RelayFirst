# Layer 0 存活测量：决策简报（Q1）

> **状态：待你裁决。** 属 `impl-planning.md §6`（Layer 0 设计）。**在 Q1 定案前，Layer 0 代码无处下手。**
> 关联：`incentive.md §3/§10.3`、`ADR-0004`（节点无密钥）、`ADR-0009 D3`（per-key domain 白名单）。
>
> **一句话**：Layer 0 卡在**设计**，不卡在代码 —— 因为"节点活着"这件事，**节点自己说了不算**。

---

## 1. 问题（为什么不能"节点自己上报"）

`incentive.md §3` 要求存活证据**不接受自证**（"发放挂钩可验证存活信号"）。而 **节点无密钥**（`ADR-0004`，CI 强制）：

```
节点进程结构上【不能签任何东西】 → 节点的"我在线"日志【不可归因】→ 不可信
若采信它 = 采信一串可随意编造的、无签名的自我声明 = 自证
```

**所以存活证据必须由【他人】签。** 「他人是谁」就是 Q1。

---

## 2. 三个选项：各选会怎样

| | **A. Verifier 签心跳** | **B. 邻居观测（gossip）** | **C. 挑战式 proof-of-serve** |
|---|---|---|---|
| **谁签** | 独立 **verifier**（有密钥）| 其他节点**无密钥** → 仍需外部签 | 任意**挑战者**（外部 signer）|
| **证据** | "我在 slot t 收到 node N 响应"，签 `assertion-1` | 对等观测，客户端聚合 | 对某个键的 challenge-response |
| **现有物** | ✅ verifier + `assertion` + D3 白名单**都在** | ❌ 无 gossip 层 | ❌ 无 |
| **新 domain？** | **不需要**（`assertion-1` 已在 verifier 白名单）| 需要（新建签名者身份）| 需要（外部 signer）|
| **主要弱点** | **verifier–node 可串谋**（须 A≠B，仿 S4-6）| 节点不可签 → 证词弱；**新协议** | 引入交互协议；sybil 挑战者 |
| **每 epoch 噪声** | 1008 slots × ~200B ≈ 200KB/verifier（SQLite 无压力）| 随邻居数放大 | 按挑战量 |
| **工程量** | **中**（心跳记录 + 阈值 + 喂 `node_tenure` + tier 加权进份额）| 高（gossip 协议）| 高（协议 + 外部 signer）|
| **与现有架构** | ✅ 最贴（复用 S10 verifier 身份、S4-6 防串谋思路）| ⚠️ 要新建层 | ⚠️ 最远 |

**倾向（供参考，非结论）**：**A** 复用已有物最多、与 `assertion-1` 白名单兼容、无新 domain；它的核心风险（**verifier 与 node 串谋**）在仓库里**已有同型防线**（S4-6：验证者 ≠ 产出者、比例上限、`fail closed`），可复用其思路。

## 3. farm ROI 首算（`internal/devtools/farmroi.go`，launch-blocking 的输入）

**可运行、可复现**：`go run internal/devtools/farmroi.go`。**不定价积分**（A5），输出是无量纲的"**每美元托管成本换多少分**"与"**break-even 需要每分值多少**"。

**种子假设**（都可改）：100 节点 × \$5/月，52 epoch/年，Phase 1 节点池 50%。

| 农场类型 | 其他节点数 | 农场份额 | 每年/节点（分）| break-even 需 1 分值 |
|---|---|---|---|---|
| **全新（tenure<3）** | —— | **0（无资格）** | **0** | ∞ |
| 成熟（3–5，1.0×）| 1,000 | 9.1% | 64,919 | **$0.00092** |
| 成熟（3–5，1.0×）| 10,000 | 1.0% | 7,070 | **$0.00849** |
| 耐心（12+，1.25×）| 1,000 | 11.1% | 79,345 | **$0.00076** |
| 耐心（12+，1.25×）| 10,000 | 1.2% | 8,816 | **$0.00681** |

**读法（诚实版）**：
- ✅ **tenure ≥ 3 门槛**是真防线：**全新农场前 3 个 epoch 收益为 0** —— 买机器不能立刻挖。
- ⚠️ **但门槛只是"等 21 天"**，不是不可逾越。耐心农场（等 12 epoch）还拿 **1.25×**。
- ⚠️ **break-even 的每分价值很小**（\$0.0002–\$0.008）—— 因为积分**未定价**，这个数字**只能靠"积分最终值多少"来判**，而那**恰恰是未决的**（`incentive.md §10.11` 的 r）。
- **结论**：**farm ROI 的"无利可图"无法在积分定价前证明。** 能证明的是"**门槛 + tier + 稀释**把农场的份额压到需要**很低的每分价值**才回本"—— 但"很低"到底算不算"够低"，取决于 r。

## 4. 因此 Q1 与 X、r 是【耦合】的

```
Q1（谁签存活）  → 决定 Layer 0 能不能测
X（乘数上限）   → 决定 PoSR 加成强度
r（每分兑换）   → 决定 farm ROI 能否被证"无利可图"
```

**三者不能孤立定。** 一个自洽的次序：**先 Q1（拿到真实的"合格 epoch"数据）→ 再 X（有了节点数再定乘数）→ 再 r（有了节点经济再判 farm ROI）**。

## 6. 决策者结论（2026-10-08）—— 提案撰写者据此开工

> 以下三点是决策者的结论，**权限高于本文档其余部分**。提案撰写者据此直接产出 **Layer 0 心跳协议提案**
> （可直接实现层：新的 attestation 类型 + 存储 + 阈值 + `settle` 接线）。三条**耦合**，须一起读。

### 6.1 Q1 = **选 A（verifier 签心跳）**

**理由**：
- **复用最多**：verifier 身份、`assertion` 包、`assertion-1` domain 白名单**都已在**；**无需新 domain、无需新签名者身份**。
- **无需新协议层**：B（gossip）/ C（挑战）都要**新建**协议；A 只加"心跳记录 + 阈值"，与现有 S10 架构同构。
- **风险有现成同型防线**：核心风险是 **verifier–node 串谋**（A 自证 A），而仓库里**已有 S4-6**（验证者 ≠ 产出者、比例上限、无 activity 时 `fail closed`）作**可直接复用的模板**。
- **噪声可控**：1008 slots × ~200B ≈ **200KB/epoch/verifier**（SQLite 无压力），已在 `incentive.md` 记过。

→ **提案须自带**：心跳 attestation 的类型/频率/slot 定义 + **防串谋约束（仿 S4-6，须 A≠B）** + 阈值（95% 达标、单次掉线上限 X）+ **喂入 `node_tenure`** + **tier 加权进 Layer 0 池**。

### 6.2 乘数（1.25×）问题 —— 提案须**正面处理**，不是照搬

**问题陈述**：PoSR 的 1.25× 是"**跑自己节点多赚 25%**"。但：
- 它**只跟绑定（binding）挂钩**，**与节点是否真的可靠无关** —— 一个常年宕机、但**绑定了**的节点，其 agent 照样拿 1.25×。
- 于是**租一个"挂名" verifier 身份**（甚至自己左手绑右手）就能拿满加成，**可靠性测量（Q1 的产物）根本没被用上**。
- 这正是 Layer 0 存在的理由（奖励**可靠性**）被 PoSR 绕过的地方。

→ **提案须回答**：1.25× 是否应**条件于**该节点通过 Q1 的存活门槛（tenure ≥ 3 / 当期达标）？若是，**绑定 + 存活**双条件；若否，**说明为何挂名绑定不算滥用**。**不得默认照搬 1.25×。**

### 6.3 r（兑换比例）是**政策武器** —— 不是"待填的参数"

**要点**：由于**积分不定价**（A5），**r 是唯一的"价值旋钮"**。它**同时**决定：
1. **farm ROI 的"无利可图"能否成立**（§3 的 break-even 依赖它）；
2. **挖矿激励强度**（每分未来值）；
3. **TGE 分配的政治**。

**因此**：**r 只在 TGE 时一次性公布，是可**战术性**使用的** —— 用来**证成"矿场无利可图"**（把 r 定在使 break-even 高于可行值的位置），并在**不触碰 A5**（不承诺回报）的前提下**调节激励**。

→ **提案须**：把 r 从"待填参数"重新表述为**政策工具**，并说明**它与 farm ROI 判定、与 X 的关系**（三者耦合，见 §4）。**不得把 r 当成一个孤立数字。**

- [ ] **1.25× 的条件**（6.2）显式写出，不照搬。
